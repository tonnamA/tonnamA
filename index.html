Quick Review Sheet & Exam Traps

อ่านหน้าห้องสอบ
Substrate + Condition Reaction ที่ควรนึกถึง ข้อสังเกตหลัก
Alkane + Br₂ / Cl₂ + light/UV Substitution มี HBr หรือ HCl เกิดขึ้นเป็น Byproduct
Alkene + Br₂ (ในที่มืด หรือมีแสง) Addition พันธะคู่ C=C หายไป กลายเป็น dibromoalkane ไม่มี HBr
Alkene + H₂ Addition (Hydrogenation) กลายเป็น Alkane
Alkane → Alkene + H₂ Elimination (Dehydrogenation) ดึง H₂ ออก เพื่อสร้างพันธะคู่ C=C

Trap 1: Br₂ ไม่ได้แปลว่า Substitution เสมอ!

ต้องดูสารตั้งต้นเสมอ! ถ้าเป็น **Alkane** + Br₂ + แสง $\rightarrow$ Substitution แต่ถ้าเป็น **Alkene** + Br₂ $\rightarrow$ Addition

Trap 2: ดู Byproduct (HBr/HCl) เป็นเบาะแส

ถ้าสมการมี $HBr$ ออกมาด้านขวา = **Substitution** แน่นอน แต่ถ้าบวก $Br_2$ แล้วเข้าโมเลกุลหมดไม่มีเศษ $HBr$ = **Addition**

Trap 3: Isomer ต้องเช็คความสมมาตร (Symmetry)

การวาดกลับซ้าย-ขวา หรือกลับบน-ล่าง ถือเป็นโมเลกุลเดียวกัน ให้ตั้งชื่อตามหลัก IUPAC เพื่อตรวจสอบชื่อซ้ำ

Trap 4: Reverse Combustion ไม่ต้องเดาสูตร

ถ้าได้ $a\text{ mol } CO_2$ และ $b\text{ mol } H_2O$ สูตร Hydrocarbon คือ $C_aH_{2b}$ เสมอ! (เนื่องจาก $CO_2 1\text{ mol}$ มี C 1 ตัว และ $H_2O 1\text{ mol}$ มี H 2 ตัว)
